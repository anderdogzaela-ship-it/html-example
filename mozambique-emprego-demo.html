Sobre a Vaga

A Vodacom Mozambique esta a recrutar um Desenvolvedor Web Full Stack para integrar a nossa equipa de tecnologia. Sera responsavel pelo desenvolvimento e manutencao de aplicacoes web que servem milhoes de utilizadores em todo o pais.

Responsabilidades

  • Desenvolver e manter aplicacoes web em PHP com MySQL
  • Criar interfaces responsivas com HTML, CSS e JavaScript
  • Colaborar com a equipa de produto na definicao de funcionalidades
  • Garantir performance e seguranca das aplicacoes
  • Participar em code reviews e manter documentacao actualizada
  • Integrar APIs externas e servicos de terceiros

Requisitos

  • Minimo 3 anos de experiencia em desenvolvimento web
  • Dominio solido de PHP, MySQL, HTML, CSS e JavaScript
  • Experiencia com frameworks como Laravel ou Symfony
  • Conhecimentos de controle de versao com Git
  • Boa capacidade de comunicacao e trabalho em equipa
  • Licenciatura em Informatica ou area equivalente (preferido)

Oferecemos

  • Salario competitivo de MZN 45.000 mensais
  • Trabalho remoto com reunioes semanais
  • Subsidio de internet e equipamento
  • Seguro de saude
  • Formacao continua e certificacoes
  • Ambiente de trabalho dinamico e inovador

Candidaturas aceites ate 30 de Julho de 2026. Apenas candidatos seleccionados serao contactados.
