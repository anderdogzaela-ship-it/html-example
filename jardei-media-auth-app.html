Captura com selo inforjavel de ponta a ponta

O aplicativo gera um hash SHA-256 ancorado no servidor Firebase para cada midia capturada. O timestamp e definido pela Cloud Function e fica fora do controle do dispositivo. Clique na tela do celular para simular o fluxo completo.

1

Camera com metadados em tempo real

GPS + horario do servidor exibidos antes da captura

2

Hash SHA-256 gerado no servidor

Cloud Function ancora o hash fora do controle do cliente

3

Selo verde e metadados verificados

Hash + localizacao + timestamp imutavel no Firestore

Detalhe de arquitetura: o timestamp no hash nao vem do dispositivo - vem do Firebase Cloud Function. Isso impede que alguem manipule o relogio do celular para forjar uma data diferente na midia capturada.
