Segurança e auditoria
Como o Cofre protege os arquivos e o acesso de cada cliente

Criptografia

Conexão via HTTPS/TLS em todo o envio e download. Arquivos armazenados de forma criptografada, mesmo em repouso.

Acesso por cliente

Cada cliente acessa com login próprio e enxerga apenas os arquivos dos seus próprios veículos, nunca os de outro cliente.

Verificação de integridade

Um hash (SHA-256) é gerado a cada envio e a cada devolução, confirmando que o arquivo não foi alterado ou corrompido no caminho.

Log de auditoria

Todo envio, análise, edição e devolução fica registrado com usuário, data e hora — nada é apagado ou sobrescrito silenciosamente.

Backup automático

Cópias de segurança periódicas para evitar perda de arquivo em caso de falha.

Acesso responsivo

Área restrita adaptada para celular, para o cliente enviar foto de documento direto do carro ou da oficina.
